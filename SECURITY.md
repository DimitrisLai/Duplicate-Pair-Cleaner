# Security and data safety

Duplicate Pair Cleaner is a local-only Python utility. It scans filenames in a user-selected folder and does not upload data, track users or inspect media contents. Default cleanup moves unnecessary files into a dated backup folder.

**Important:** It is a filename-based organizer, not a content-based deduplicator. Filenames do not prove two files are identical. Review every proposed action and keep independent copies of important files. Power loss and filesystem failures cannot always be rolled back.

## Reporting problems

Please do not post private file lists, names, paths, audio, videos or photos. Create a small reproduction using fictional filenames and open a GitHub Issue. If GitHub private vulnerability reporting is enabled, use it for security issues.

Please review third-party forks carefully before executing them.
